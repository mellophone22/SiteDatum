# SiteDatum 1.2.1

SiteDatum 1.2.1 refines the in-application brand lockup and republishes the Windows package with the corrected presentation.

## Changes

- Removes the raster overlay that caused a stray white edge and an incomplete color transition around the capital **D**.
- Renders the in-app SiteDatum lockup with the approved application icon, crisp white **Site** lettering, and a controlled teal-to-cyan **Datum** transition.
- Applies the corrected lockup to both the main sidebar and first-run workspace setup.
- Preserves the SiteDatum Windows executable icon and all existing local data compatibility identifiers.

## Install

Download and run `SiteDatum_1.2.1_x64-setup.exe`. The installer is not code-signed, so Windows SmartScreen may show an unrecognized-publisher warning.

Existing SiteDatum and earlier installations can upgrade without relocating project data.
