# AnyDesk 1.1.0

This release introduces a project-centric workspace and completes the UX 1.1 work-package series.

## Highlights

- Added a shared workspace state with explicit project selection and reliable context inheritance.
- Reworked Home, Projects, Tasks, RFIs, Submittals, Files, Project Controls, Notes, Contacts, Activity, and Settings around the active project.
- Added detail panels, richer task editing, lifecycle-aware RFI and submittal workflows, project controls hierarchy, phase prioritization, and project-scoped numbering suggestions.
- Added a keyboard-accessible search palette, Quick Capture improvements, shared confirmation and feedback dialogs, and a first-run setup flow.
- Improved recovery visibility, responsive behavior, reduced-motion support, focus management, keyboard navigation, and accessibility semantics.
- Expanded automated frontend and Rust coverage for workspace state, lifecycle rules, persistence, filesystem safety, backup/recovery, and realistic task volumes.

## Installation

Install `AnyDesk_1.1.0_x64-setup.exe`. Existing local projects, files, and SQLite workspace data are retained during the upgrade.

The binaries are not code-signed. Windows SmartScreen may display an unrecognized-publisher warning.
