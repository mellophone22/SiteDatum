# SiteDatum 1.3.0

SiteDatum 1.3.0 gives the Project Engineer workspace a more distinctive, responsive visual system while preserving its dense, local-first working model.

## Changes

- Applies the SiteDatum navy, teal, and orange identity throughout navigation, Home, registers, forms, detail panels, dialogs, and onboarding.
- Reworks Home into a compact operational instrument strip with clearer immediate-work and response queues.
- Adds short, functional view and panel transitions with complete Windows reduced-motion support.
- Adds an About page with the full SiteDatum logo, “The project record you control,” creator credit for Francisco Cabrera, and the running software version.
- Makes About available from System navigation and workspace search.
- Improves short-window navigation, responsive header behavior, Quick Capture sizing, focus states, and table readability.

## Install

Run `SiteDatum_1.3.0_x64-setup.exe`. The installer is not code-signed, so Windows SmartScreen may show an unrecognized-publisher warning.

The application identifier is unchanged. Existing SiteDatum installations retain their local workspace database, settings, backups, project-root configuration, and optional synchronization session during the upgrade.
