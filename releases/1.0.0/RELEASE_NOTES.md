# AnyDesk 1.0.0

This release completes the local-first Windows project engineering workspace through WP18.

## Highlights

- Daily Overview, Attention queues, task completion gauges, saved views, and Quick Capture.
- Full Projects, Tasks, RFIs, Submittals, Files, Drawings, Notes, Contacts, and Activity workflows.
- Excel-template-based RFI PDF generation.
- Project controls registers for meeting minutes, procurement, change events, transmittals, and milestones.
- Field and commissioning registers for punch items, daily reports, startup checks, commissioning checks, and commissioning issues.
- Transactional project templates, bulk status actions, previewed CSV/Excel import, and filtered CSV/Excel export.
- Printable versioned reports for weekly status, open items, meeting minutes, transmittals, submittal covers, and contacts.
- Combined date register and opt-in Windows reminders while AnyDesk is running.
- Backup inventory, integrity/count preview, safety backup, confirmed restore, missing-file diagnostics, and conflict visibility.
- Optional Supabase metadata sync with a dedicated OneDrive project root and explicit conflict resolution.

## Installation

Run `AnyDesk_1.0.0_x64-setup.exe` on Windows 10 or Windows 11. The portable `AnyDesk.exe` is also attached for testing and troubleshooting.

The binaries are not code-signed. Windows SmartScreen may display an unrecognized-publisher warning.
