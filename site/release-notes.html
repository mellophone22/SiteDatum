What this release establishes

  • A local-first project workspace for tasks, RFIs, submittals, files, notes, contacts, and project controls.
  • Accountless Free use for up to three active projects, with ordinary project work available offline.
  • Non-destructive Free and Pro entitlement behavior: expiration does not delete, hide, move, or make existing records uneditable.
  • A neutral SiteDatum RFI PDF output, plus customer-owned custom PDF templates for verified Pro use.
  • Local backup, recovery, CSV export, and normal Windows-file ownership.

Upgrade verification

In-place upgrade and reinstall testing retained the existing fictional workspace, tasks, RFI, submittal, and registered file records. The installer does not promise automatic updates; each Early Access release is downloaded and verified separately.
