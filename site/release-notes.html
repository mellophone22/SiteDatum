What changed in 1.4.4

  • A new in-app Help section explains the local-first workflow, Free and Pro boundaries, backup and recovery, licensing, privacy, and private support.
  • Startup recovery and backup validation now surface safe, actionable recovery states without silently replacing customer data.
  • Free portability now exports the complete core workspace as protected CSV files, while existing records remain editable after entitlement changes.
  • Signed-in users can review active Windows computers and remove another device without exposing device names or workspace information to the licensing service.
  • Windows paths, files, PDFs, and release provenance received additional validation and regression coverage.

Upgrade verification

In-place upgrade and reinstall testing retained the existing fictional workspace, tasks, RFI, submittal, registered file records, and local settings. The installer does not promise automatic updates; each Early Access release is downloaded and verified separately.
