System requirements

Built for a Windows project workstation.

What SiteDatum 1.4.1 needs to install, store local records, and verify optional Pro access.

Applies to SiteDatum 1.4.1

Operating system
Windows 10 or 11
Architecture
64-bit
Runtime
Microsoft Edge WebView2

Computer and storage

SiteDatum requires a 64-bit Windows 10 or Windows 11 computer with Microsoft Edge WebView2 Runtime available. Keep sufficient local storage for the SiteDatum database, backups, exports, and the project documents that remain in your normal Windows folders.

Display and input

The application supports keyboard and pointer use, a minimum working window of 760 × 540 pixels, and layouts verified at 200% Windows display scaling. A larger desktop display is recommended for dense project registers.

Connectivity

Free does not require an account, and ordinary local project work continues without an internet connection. Internet access is required when purchasing Pro, signing in for paid entitlement recovery, refreshing entitlement, or opening Stripe-hosted billing surfaces.

Project storage

Choose an existing local folder or an accessible Windows network path as the project root. Project documents remain normal Windows files. SiteDatum never requires those documents to be uploaded to a cloud service for ordinary project work.

Unsigned installer

SiteDatum 1.4.1 is an unsigned Windows Early Access release. Microsoft Defender SmartScreen may warn, and Smart App Control, antivirus software, or an organization policy may block installation. Do not disable those protections. Managed devices may require administrator approval or may not be eligible for this release channel.
