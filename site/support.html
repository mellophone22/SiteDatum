Support

Pre-release support channel

SiteDatum is under active development and public distribution is deferred. General questions and reproducible software issues can be submitted through the public GitLab project.

Before posting publicly

Do not include project names, customer names, contacts, file paths, documents, screenshots of private records, database files, license credentials, payment information, or secrets. Replace real project information with a minimal fictional example.

Report an issue

Open the public issue tracker →

Include the SiteDatum version, Windows version, what you expected, what happened, and minimal steps that reproduce the problem without customer content.

Billing support

Production billing is not open. Never post payment information or billing identifiers in a public issue. A private billing-support channel will be published before paid launch.

Data safety

Keep the current workspace database and backups when troubleshooting. Never delete, overwrite, or move a project folder as a repair step unless you have independently verified backups and understand the consequence.
