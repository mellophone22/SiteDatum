Support & guidance

Get help without exposing project data.

Choose the right support path for installation, billing, privacy, or reproducible software issues.

Early Access support channel

SiteDatum is under active development and the controlled unsigned Early Access download is available from the canonical SiteDatum website. Use the public issue tracker only for reproducible software problems that can be described with fictional information.

Protect private information

Do not include project names, customer names, contacts, file paths, documents, screenshots of private records, database files, license credentials, payment information, or secrets in GitHub issues. Replace real project information with a minimal fictional example.

Unsigned installer support

Read the Windows Early Access guide before purchasing or downloading. SiteDatum Support will never ask you to disable Microsoft Defender, Smart App Control, antivirus software, or an organization’s security policy. If installation is blocked, keep the protection enabled and contact private support.

Private support

For billing questions, a policy-blocked installation, account or entitlement recovery, suspected security or privacy problems, or anything that cannot be safely discussed in public, email supportsitedatum@protonmail.com.

Describe the symptom, SiteDatum version, Windows version, and the approximate time it occurred. Do not email passwords, authentication codes, full payment-card information, project documents, workspace databases, or secrets. SiteDatum Support may request a redacted request or event identifier when it is needed to investigate.

Report a public software issue

Open a public bug report →

Include what you expected, what happened, and minimal reproduction steps using only fictional project information. Use private support instead if you are unsure whether the report is safe to publish.

Data safety

Keep the current workspace database and backups when troubleshooting. Never delete, overwrite, or move a project folder as a repair step unless you have independently verified backups and understand the consequence.
