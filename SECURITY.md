# SiteDatum security reporting

Report suspected security or privacy problems privately to `supportsitedatum@protonmail.com`.

Do not open a public GitLab issue for a suspected vulnerability, exposed credential, cross-customer access problem, billing/account concern, or accidental collection of private project information.

Include the SiteDatum version, Windows version, approximate occurrence time, observed behavior, and the smallest safe reproduction description. Do not send passwords, authentication codes, full payment-card information, project documents, workspace databases, private customer data, provider payloads, or secrets. If an identifier is needed, send only the specific redacted request or event identifier requested by SiteDatum Support.

Public GitLab issues remain appropriate for ordinary reproducible software defects that can be demonstrated entirely with fictional information.
