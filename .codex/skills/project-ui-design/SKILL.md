# Project UI Design Review Skill

Use this skill whenever creating, changing, or reviewing a major screen/component.

## Procedure
1. Read `docs/design/DESIGN_SYSTEM.md`, `UX_RULES.md`, `UI_ANTI_PATTERNS.md`, and `SCREEN_SPECIFICATIONS.md`.
2. State the screen's primary user job in one sentence.
3. Identify the highest-frequency actions and information.
4. Design for realistic data volume.
5. Prefer lists/tables and direct manipulation over decorative containers.
6. Verify keyboard, empty, loading/working, error, disabled, hover, focus, selected, and destructive states as applicable.
7. Check that every visible control has implemented behavior.
8. Check that color is not the sole state signal.
9. Remove unnecessary cards, pills, shadows, gradients, headings, animation, and whitespace.
10. Run a final question: does this feel like a mature Project Engineer tool or a generated SaaS template? If the latter, revise before declaring complete.
