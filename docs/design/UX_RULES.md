# UX Rules

1. Optimize for repeated daily use.
2. Preserve context with inline editing/drawers where appropriate.
3. Make saved/waiting/missing/filtered/archived states obvious.
4. Quick capture starts minimal.
5. Waiting is a first-class workflow.
6. Related records are one click away.
7. Persist useful filters/sorts and recent context.
8. Never silently overwrite/delete files.
9. Distinguish deleting metadata from deleting physical files.
10. Empty states teach the next useful action.
11. Errors explain what happened and recovery.
12. Search/quick-add work from anywhere.
13. Critical actions are not hover-only.
14. Active filters are obvious.
15. No UI theater: visible controls work.
