# Screen Specifications

## Attention
Grouped actionable rows: project, item, reason, due/waiting context, status, quick actions. No card wallpaper.

## Projects
Dense table/list with search/filter/sort/pin/archive. Enter/double-click opens. Safe context menu.

## Project Overview
Compact header + Open Folder. Current attention, concise summary, meaningful recent activity, pinned notes.

## Tasks
Title, status, priority, due/follow-up, waiting-on, category. Fast inline status changes and strong filters.

## RFIs / Submittals / Drawings
Use professional tables with identifiers, status/revision/date/recipient context. Detail views contain attachments and relationships. Drawing current/superseded state must be obvious.

## Files
Filesystem-oriented registered-file list with Show in Explorer. SiteDatum reveals the registered file in Windows Explorer and does not directly open it. Do not replace Explorer.

## Notes / Contacts / Activity
Fast notes, compact contacts, meaningful chronological activity.

## Settings
Only real settings: project root, backup/export, appearance if implemented, genuine defaults.
