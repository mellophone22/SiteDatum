# Interaction & Accessibility

- Ctrl+K: command/search palette.
- Ctrl+N: context-sensitive create where safe.
- Esc closes top transient layer without discarding saved work.
- Enter opens selected row; keyboard navigation for major lists.
- Right-click exposes contextual actions.
- Drag/drop only onto labeled targets; show operation before destructive movement.
- Inline edits report failure without losing previous value.
- Remember useful navigation/window state.
- Unsaved long-form edits must not vanish accidentally.
- Destructive confirmations name target and consequence.

Accessibility target: WCAG 2.2 AA principles where applicable. Full keyboard core workflows, visible focus, semantic labels, sufficient contrast, no color-only meaning, reduced-motion support, logical focus order, associated validation errors, accessible names/tooltips for icon-only controls.
