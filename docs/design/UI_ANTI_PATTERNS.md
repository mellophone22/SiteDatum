# UI Anti-Patterns

Reject by default: Welcome-back hero dashboards; giant metric cards; everything in rounded cards; gradients/glassmorphism; excessive shadows/whitespace; huge headings; emoji icons; pill-shaped everything; decorative charts; fake notifications/activity/search/filter/export; complex work in modals; critical hover-only actions; ambiguous drag/drop behavior; color-only status; competing primary actions; slow decorative animation; illustration-heavy empty states; demo content in production; Coming Soon controls; duplicate components solving the same interaction differently.

Review screens at realistic scale: 25 projects and hundreds of records, not three demo cards.
