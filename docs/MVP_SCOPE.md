# MVP Scope

## Include
Windows desktop shell; configurable project root; SQLite+migrations; Project CRUD/archive/pin; automatic folder creation; Attention; Tasks; RFIs; Submittals; Drawings/files; explicit Copy/Move/Register; Notes; Contacts; relationships; Activity; global search; command palette; filters/sorts; recent projects; remembered navigation; Open/Show in Explorer; local backup/export; tests.

## Exclude
AI; email/calendar integration; web/mobile; collaboration, organizations, and role-based access; OCR/content indexing; PDF/CAD markup; engineering calculations; time tracking; advanced analytics; plugin marketplace.

## Commercial launch exception
A post-MVP commercial layer may add accountless Free use, minimal paid-customer identity, centralized entitlements, merchant-of-record hosted billing, a customer portal, signed updates, and explicitly approved privacy-safe operational telemetry. These services must not receive project content or become a dependency for ordinary local work. Metadata sync is deferred from the initial commercial launch; its separately consented legacy path is contained to computers with prior local Sync evidence and is not the licensing authority.

Do not smuggle Phase 2 features into MVP.
