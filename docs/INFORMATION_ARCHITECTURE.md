# Information Architecture

## Global navigation
Attention, Projects, Search/Command, Settings. RFIs/Submittals/Drawings primarily live inside projects.

## Project workspace
Overview, Tasks, RFIs, Submittals, Drawings, Files, Notes, Contacts, Activity.

## Attention
Grouped by usefulness: Overdue, Today, Follow-up/Waiting, Upcoming, RFI/Submittal queues.

## Projects
Dense searchable/sortable list with number, name, phase/status, next attention item, open count, recency, pin/archive.

## Detail behavior
Prefer drawers/side panels for quick inspection when they preserve context; use full pages for complex work. Avoid long editing in cramped modals.
