# User Workflows

## Morning
Launch -> Attention shows overdue/today/follow-up/waiting/upcoming -> act without hunting for project -> changes update immediately.

## New project
Quick action -> metadata -> confirm exact path/folder preview -> create DB record + folder tree -> report partial failures precisely -> open Overview.

## Quick task
Global quick-add -> title -> project via recent/fuzzy selector -> optional due/priority/status -> save without leaving context.

## Quick capture
Ctrl+Shift+N or Quick capture -> choose Task, Note, RFI draft, or Contact -> enter the minimum required information -> save -> open the corresponding workspace with refreshed data.

## Saved task view
Choose filters and sort -> Save current view -> name it -> restore it from the Saved view selector. Changing a restored filter returns the selector to Current filters; deleting the saved view does not delete any records.

## Project overview
Choose a working project or All projects -> Overview -> review active tasks, immediate work, open responses, and recent project notes -> open the underlying register to act.

## Waiting
Set Waiting -> capture `Waiting on` + optional follow-up -> record waiting start -> resurface when follow-up is due.

## RFI
Draft -> Open when submitted -> Response Received -> Closed after review. Preserve linked tasks/files/drawings. Save only, or save and create a PDF from the approved RFI template in an explicitly selected location.

## Submittal
Preparing -> Submitted/Under Review -> disposition -> optional resubmission task/revision -> Closed.

## File
Drop/select -> explicitly Copy, Move, or Register -> prevent overwrite -> store path/metadata -> Open / Show in Explorer.

## Missing file
Show Missing; offer Locate File / Remove Reference. Never silently delete metadata.
