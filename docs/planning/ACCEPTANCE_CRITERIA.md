# Acceptance Criteria

MVP is acceptable when:
- launches reliably on Windows without network access;
- data survives restart;
- project creation safely creates the documented folder tree;
- partial filesystem failures are never reported as success;
- tasks support due/follow-up/waiting and populate Attention correctly;
- RFI/submittal lifecycles work;
- files support explicit Copy/Move/Register and never silently overwrite;
- missing files are recoverable;
- search finds all core entity types;
- keyboard navigation/command palette work for core flows;
- archive/delete behavior is safe and understandable;
- all visible controls are functional;
- tests/typecheck/lint/build pass;
- interface passes the project UI skill review at realistic data volume.
